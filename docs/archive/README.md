# Archived project documents

This directory preserves historical audits, readiness reports, handoffs, and agent notes for provenance. These files describe the repository at a point in time and are not the current source of truth.

For current project guidance, start with `README.md`, `BRAIN.md`, `PROJECT_MAP.md`, `PRODUCTION_SECURITY_CHECKLIST.md`, `LAUNCH_READINESS_CHECKLIST.md`, and `docs/engineering/AGENT_RULES.md`.

Do not rewrite archived evidence to make it match the current code. When the project changes, update the active documentation and leave the historical record intact.
